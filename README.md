# 試験対策クイズ集

経済学部の科目を復習するための学習ツール集です。全7科目・858問＋用語229語。

**公開URL**: https://adachi-0518.github.io/keizai-quiz/

## 使い方

`index.html` をブラウザで開くか、公開URLにアクセスするだけです。インストールやビルドは不要です。

どの科目も画面の作りは同じです。

1. 上の帯で範囲（章・回）を選ぶ。「ぜんぶ」なら全範囲から続けて出題されます
2. 1問ずつ解く。答えるとその場で正誤と解説が出ます
3. 一周したら「✕だけ復習」で、間違えた問題だけをもう一度回せます

そのほか、
- **一覧で読む** — 全問を答えつきで通して読めます。「答えを隠す」を押せば読みながら解けます
- **キーボード操作** — <kbd>1</kbd>〜<kbd>9</kbd> で解答、<kbd>→</kbd> <kbd>←</kbd> で前後の問題へ
- **要点ノート** — 銀行論・金融政策論は、いま解いている範囲の要点を問題の上から開けます

## 特徴

- **内容に合った出題形式** — 用語をおぼえる科目は穴埋め、制度の細部を問う科目は「2つ選ぶ」、理論の取り違えを潰す科目は誤りの語句を選ぶ形式にしています
- **論述・記述への対応** — 銀行論・金融政策論・西洋経済史・ビジネスモデル論には、答案の組み立て方を示した骨格ノートを収録しています
- **選択肢の並びは固定** — 正解の位置は分散させてあるので、位置で覚えてしまうことはありません
- **解答の自動保存** — ブラウザを閉じても続きから再開できます。記録はブラウザの中だけに保存され、どこにも送信されません
- **外部依存ゼロ** — 単体のHTMLファイルなので、オフラインでも動きます。スマホ・ダークモード対応
- **読みやすさと操作性** — デジタル庁デザインシステムを参考に、文字サイズ、余白、操作領域、キーボードフォーカス、状態表示を全ページで統一しています

## 技術的な構成

各科目は独立した単一のHTMLファイルです。CDNもフレームワークも使わず、素のHTML/CSS/JavaScriptで書かれています。学習の記録は `localStorage` に保存されます。

共通の表示・アクセシビリティ改善は `tools/apply-dads.js` で各HTMLへ反映できます。

```
index.html      トップページ
ginko/          銀行論
shakai/         社会保障論
jinteki/        人的マネジメント
soshiki/        組織行動論
soshiki-read/   組織行動論（通し読み版）
kinyu/          金融政策論
seiyo/          西洋経済史
seiyo-card/     西洋経済史（用語3行説明カード）
bizmodel/       ビジネスモデル論
```

## 内容について

出題は一般的な学術概念にもとづき、独自の文章で作成しています。講義資料そのものの複製ではありません。

内容の誤りを見つけた場合は Issue でお知らせいただけると助かります。
