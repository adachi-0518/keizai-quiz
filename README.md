# 試験対策クイズ集

経済学部の科目を復習するための学習ツール集です。全6科目・679問＋用語76語。

**公開URL**: GitHub Pages を有効化すると発行されます

## 収録科目

| 科目 | 形式 | 問題数 |
|---|---|---|
| 銀行論 | 4択＋記述対策 | 119 |
| 社会保障論 | 5択から2つ選ぶ | 120 |
| 人的マネジメント | 穴埋め（選択／記述の2モード） | 292 |
| 組織行動論 | 間違い探し（クリックで指摘） | 52 |
| 金融政策論 | 4択＋論述骨格ノート | 33 |
| 西洋経済史 | 用語説明＋4択＋答案設計図 | 用語76／4択63 |

## 特徴

- **試験の出題形式に合わせた演習** — 科目ごとに形式を変えています。穴埋め試験には穴埋めを、間違い探しの試験にはクリックで誤りを指摘する形式を、用語説明が出る科目には模範解答つきの想起練習を用意しました
- **論述・記述への対応** — 銀行論・金融政策論・西洋経済史には、答案の組み立て方を示した設計図を収録しています
- **選択肢は毎回シャッフル** — 正解の位置が固定されないので、パターンでは解けません
- **解答の自動保存** — ブラウザを閉じても続きから再開できます
- **間違えた問題だけ復習** — 弱点だけを効率よく回せます
- **外部依存ゼロ** — 単体のHTMLファイルなので、オフラインでも動きます。スマホ・ダークモード対応

## 使い方

`index.html` をブラウザで開くか、公開URLにアクセスするだけです。インストールやビルドは不要です。

## 技術的な構成

各科目は独立した単一のHTMLファイルです。CDNもフレームワークも使わず、素のHTML/CSS/JavaScriptで書かれています。学習の記録は `localStorage` に保存されます。

```
index.html      トップページ
ginko/          銀行論
shakai/         社会保障論
jinteki/        人的マネジメント
soshiki/        組織行動論
kinyu/          金融政策論
seiyo/          西洋経済史
```

## 内容について

出題は一般的な学術概念にもとづき、独自の文章で作成しています。講義資料そのものの複製ではありません。

内容の誤りを見つけた場合は Issue でお知らせいただけると助かります。
